# Bermuda 0.8.4 — personal reports and study improvements

Pre-release candidate, prepared 22 November 2026. RPM and Flatpak builds and
packaged application checks are pending.

## Changes since 0.8.3

- My games report cards and resumable batch KataGo analysis.
- Preserved groups and weekly reports, report removal and analysis trends.
- Direct Save PDF export with dated filenames, charts and selected board diagrams;
  browser reports retain optional detailed tables and individual game pages.
- Player ranks and recorded-move markers alongside engine candidates.
- Clearer study and analysis navigation, SGF tree handling and adjustable comments.

Existing KataGo analyses are retained. PDF export uses saved report evidence;
it does not start another analysis run.

## Linux packages

- Tumbleweed x86_64: bermuda-0.8.4-1.x86_64.rpm and matching source RPM.
- Flatpak x86_64: bermuda-0.8.4-x86_64.flatpak (unsigned test bundle).

No game database, KataGo executable or neural network is bundled. Flatpak uses
its own profile and runtime; host GPU-engine compatibility is not established
by successful native operation. No new Windows package is part of this build.

## Package acceptance

Confirm About shows 0.8.4 in each package. Check startup and restart, database
access, SGF opening and saving, pattern search, study variations and comments,
KataGo setup and analysis, and report PDF export to a chosen destination.
In Flatpak, explicitly check the file chooser and access to the resulting PDF.
Sign verified packages using the existing release key before publication.
