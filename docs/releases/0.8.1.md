# Bermuda 0.8.1 — Linux testing release

Bermuda is a desktop application for studying Go games, searching local board
patterns and comparing continuations from game records. This first Linux
package candidate is intended for testers. It is not yet a general stable
release. Windows and macOS packages are not included.

## Fix in 0.8.1

Game and joseki trees now retain a dedicated minimum width beside the board.
Previously, moving the main divider could leave too little spare space and
hide the tree, preventing access to variations. The board now shrinks when
necessary so the tree stays accessible.

The maintainer confirmed the fix in the development build. The board's
orientation and the stored games are unchanged by this layout fix. No database
re-import or re-index is required.

or KataGo engine is included in either application package.

## Install the Tumbleweed RPM

Download the application RPM and public key into the same directory. Inspect
the key with:

```bash
gpg --show-keys --with-fingerprint ./bermuda-signing-key.asc
```

The Bermuda signing fingerprint is:

```text
671AE6477ACE75C95BC695A5EC2793D4263A81A4
```

Compare it against the project's published fingerprint before trusting the
key. Then run:

```bash
sudo rpm --import ./bermuda-signing-key.asc
rpm -Kv ./bermuda-0.8.1-1.x86_64.rpm
sudo zypper install ./bermuda-0.8.1-1.x86_64.rpm
```

The signature and digest checks should report `OK`. Launch **Bermuda** from
the application menu. Rust and Qt development tools are not required.

## Install the Flatpak

Install Flatpak using your Linux distribution's software manager if necessary.
Add Flathub as a per-user source for the KDE runtime, then install the downloaded
bundle:

```bash
flatpak remote-add --user --if-not-exists flathub \
  https://flathub.org/repo/flathub.flatpakrepo
flatpak install --user ./bermuda-0.8.1-x86_64-signed.flatpak
flatpak run org.bermuda.app//test
```

Bermuda is not currently listed on Flathub; Flathub supplies its runtime.
The bundle contains the signing public key. You can additionally verify the
signed checksum list below before installing it.

The menu entry is labelled **Bermuda (Flatpak test)**. If both packages are
installed, use the explicit command above to select the Flatpak. Use
`/usr/bin/bermuda-qt` to select the RPM.

The Flatpak keeps its own profile under `~/.var/app/org.bermuda.app/`; it does
not automatically reuse the RPM's settings or database. Select files and SGF
folders through its file dialogs. Start with a small collection and a new
managed database for testing.

## First use and KataGo

Let Bermuda create a managed database from your SGF folder. Its local help
includes starting points for obtaining game collections. The same application
can also study individual SGF files and explore the OGS joseki library.

For optional AI analysis, use **Set up KataGo → Install KataGo for me**.
The guided CPU installation downloads its engine and network, tests them,
and saves the setup. Experienced users may select their own engine, network
and configuration. The guided installer selects CPU compatibility and a
conservative configuration; it does not benchmark your computer or choose a
GPU engine. Flatpak custom executables must be compatible with its runtime.

## Check the downloaded files

Download the public key, checksum list and checksum signature alongside your
chosen package. After checking the public fingerprint, run:

```bash
gpg --import ./bermuda-signing-key.asc
gpg --verify SHA256SUMS.asc SHA256SUMS
sha256sum --ignore-missing -c SHA256SUMS
```

Require a good signature from the expected Bermuda key and `OK` for the
package you downloaded. GnuPG may say the key's owner is not certified by a
trusted signature; importing a key does not automatically certify its identity.

## Validation status

The 0.8.1 tree fix has passed the maintainer's development-build check.
The new RPM and Flatpak must still be built, installed and checked, and their
signatures verified before this candidate is published. These notes must be
updated with those results; 0.8.0 package checks do not establish 0.8.1 results.

The previous 0.8.0 packages passed local installation and signature checks on
Tumbleweed, including NHK database import and guided KataGo analysis surviving
a Flatpak restart.

## Remaining checks and limitations

- Clean-machine RPM dependency testing and testing on other Linux distributions
  are outstanding.
- The full file-portal, SGF export and OGS workflow checks are not all recorded
  for this Flatpak candidate.
- A complete review of bundled dependency licences remains outstanding;
  copied dependency licence files accompany the packaged application.
- Arbitrary host GPU versions of KataGo are not confirmed to work inside the
  Flatpak sandbox.
- The standalone Flatpak download has no Bermuda update repository yet. New
  test releases must be downloaded and installed explicitly.
- Windows 11 packaging is still to come.

Please report problems at https://github.com/gerryg1957/Bermuda/issues with
your Linux distribution, RPM or Flatpak choice, reproduction steps, and any
error output. Game collections and private game records need not be uploaded.
