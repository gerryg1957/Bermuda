# Bermuda 0.8.3 — KataGo study workflow

This is a pre-release candidate for testers. Package builds and validation are
pending; source tests and the maintainer's interactive study walkthrough passed
on Tumbleweed on 26 October 2026. Application checkpoint: `15ee72d`.

## Changes since 0.8.2

- Whole-game and current-position KataGo review with saved results, score graphs
  and significant-decision navigation. Open saved analysis without rerunning it.
- Clickable candidate moves and numbered graphical continuations; deeper
  investigation of candidates and player-proposed moves through **Why not this?**.
- Save a move or continuation into a study while preserving the original game.
- Clear recommendation, alternative and player-idea markers. Continuations show
  by default and can be switched off.
- Unified Library/Study navigation, grouped pattern controls and accessible
  matching games. Import opened SGFs into My games and remove saved studies
  without scrolling across metadata.
- Database task progress, checkpoints and restart recovery from the October
  database-maintenance checkpoint.

Bermuda organises evidence; KataGo evaluates; the player investigates.

## Candidate packages

- Tumbleweed x86_64: `bermuda-0.8.3-1.x86_64.rpm` and corresponding source RPM.
- Linux x86_64: `bermuda-0.8.3-x86_64-signed.flatpak` after signing.
- Windows 11 x86_64 preview: `bermuda-0.8.3-1-windows-x64.zip` and build checksum.

No game database, KataGo engine or network is bundled. Guided downloads remain
optional. Native Linux and Flatpak use separate profiles.

Extract the whole Windows ZIP before launching `Bermuda.exe`. The executable
is not Authenticode-signed. A successful build on the Windows Server runner is
not equivalent to interactive validation on Windows 11. Windows 10 remains
unverified. The reported Windows startup/memory issue remains open pending
further tester information; this release does not claim to resolve it.

## Validation before publication

The source checkpoint passed 308 tests with zero failures and four intentionally
ignored tests. Interactive candidate review, saved results, My games import,
study deletion and saving/reopening a continuation were confirmed by the
maintainer. Each newly packaged build still needs startup/restart, database
access, SGF file access, pattern search and KataGo/study checks. Record the
packaging commit and build results before publishing assets.

Deferred: Home should wait for an explicit Continue at startup, with a possible
User guide entry. Recurring personal-game analysis and the quiz are future work.
