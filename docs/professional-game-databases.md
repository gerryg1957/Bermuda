# Professional game records

Bermuda does not include a professional-game collection.

Bermuda is designed to work with SGF game records that you obtain separately.
The records remain your data; Bermuda builds its own searchable database from
the SGF files you choose to import.

## Getting started

1. Obtain professional game records in SGF format from a source whose terms
   allow you to download and use them.
2. In Bermuda, create a professional-game database, or open an existing
   Bermuda database.
3. Use **Database → Add Games…** to import one or more SGF directories.
4. Additional SGF collections can be imported later as your collection grows.

Bermuda is primarily intended for professional 19×19 collections. It does not
redistribute third-party game records.

Availability, coverage and download arrangements for public and commercial Go
game collections change over time, so source-specific guidance should be kept
current rather than being embedded permanently in the application.

You can use **My Games**, **Study**, the **Joseki Library** and other local
features without a professional-game database.
